# dsh-pet — русская версия

[中文 README](README.zh.md) · [Upstream PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)

Настольный питомец для [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness): дыхание в простое, случайные действия, повороты, прогулка по экрану, отклик на клик, перетаскивание и бросок, меню по правому клику — больше ста прозрачных роликов. Плюс анимации рабочего статуса, пузырь баланса, бормотание и чат, системные уведомления. Можно держать несколько питомцев, вынести их на **рабочий стол** (прозрачное окно поверх окон) и добавить свой вид (pet pack).

**Этот репозиторий** — форк [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet). Когда язык Harness — **`ru`**, меню, чат, пузыри, баланс, дела, лоток и ответы модели показываются по-русски. Отдельного переключателя языка у питомца нет. Upstream такой объём пока не принимает (только страницы внутри DSH); русская сборка живёт здесь.

Это не один плагин, а три части:

```
① промпты          →  ② пайплайн ассетов   →  ③ плагин
рецепты для видео     исходник → прозрачный     питомец в DSH
```

Клон репозитория позволяет собрать своего питомца: другой персонаж, другие действия, другой стиль.

## Быстрый старт

Нужны [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) с русским интерфейсом (например пакет `@goodandready/dsh-russian-lang`) и Node **≥ 22.12**.

Соберите плагин из этого репозитория (после каждого `git pull` заново):

```bash
cd dsh-pet
npm ci
npm run build
```

Подключите локальную копию. Путь замените на свой:

```bash
dsh plugin --profile desktop add "file:D:/projects/dsh_pet/dsh-pet"
# web-профиль:
dsh plugin --profile web add "file:D:/projects/dsh_pet/dsh-pet"
```

Если команда пишет «Already up to date», а код уже другой — удалите старую копию и добавьте снова:

```powershell
Remove-Item -Recurse -Force "$env:USERPROFILE\.dsh\profiles\desktop\node_modules\dsh-pet"
dsh plugin --profile desktop add "file:D:/projects/dsh_pet/dsh-pet"
```

**Перезапустите DeepSeek Harness.** Пункт «Перечитать настройки» обновляет только конфиг, не код плагина.

Пакет `dsh-pet` из npm и «установить dsh-pet» в менеджере плагинов — это **китайский upstream**, не этот форк.

Язык хоста запоминается в `%USERPROFILE%\.dsh\dsh-pet\host-locale.json`.

Требования, исходники и автономный режим — в [INSTALL.md](INSTALL.md) (пока на китайском, как в upstream).

## Что умеет плагин

Плагин не трогает ядро DSH.

- **100+ роликов**: простой, ходьба, игра, работа, диалог. Веса и свои файлы настраиваются.
- **Несколько питомцев** и свои виды (pet pack): у каждого размер, позиция и набор анимаций.
- **Три режима**: overlay в браузере DSH, прозрачное окно в десктопном приложении, автономный режим без DSH.
- **Физика**: клик, бросок, рогатка по двойному клику, столкновения питомцев.
- **Телефон**: тот же бросок пальцем; наклон, встряхивание и вибрация отключаются в настройках. Датчики — только на HTTPS или localhost.
- **Бормотание и чат**: фраза по таймеру или диалог, память, картинка, озвучка. При языке `ru` ответы на русском.
- **Голос**: синтез ответа и диктовка в поле ввода. При `ru` распознавание запрашивается на русском.
- **Баланс**: запрос к провайдеру, анимация по остатку и пузырь. При `ru` подписи пузыря русские.
- **Рабочий статус**: анимация по состоянию сессии DSH и короткая фраза над головой.
- **Дела**: список над питомцем, напоминания ближе к сроку.
- **Сон**: из меню; во сне тишина, кроме редких фраз. Поза задаётся `animations.sleep`.
- **Уведомления**: задача готова или ждёт подтверждения — клик возвращает в сессию.
- **Меню**: смена анимации, чат, домой, открыть DSH, перечитать настройки. При `ru` подписи русские, в том числе на рабочем столе.
- **Ещё**: звук клика, лоток, позиция на экране.

Подробности возможностей — [FEATURES.md](FEATURES.md), настройки — [CONFIG.md](CONFIG.md). Оба файла пока на китайском.

При языке хоста не `ru` интерфейс остаётся китайским, как в upstream. Свой текст в конфиге (имя, персона, описания мемов) не переводится.

## Что именно русифицирует этот форк

- Меню, чат, пузыри, дела, уведомления, выход в лотке, автономная страница настроек.
- Тексты пузыря баланса.
- Персона и подсказки модели, если `whisperPrompt` не меняли вручную.
- Кадры со словами: `dsh-pet/assets/memes/ru/` и `dsh-pet/assets/webm/ru/`.

Спека: [openspec/specs/pet-locale/spec.md](openspec/specs/pet-locale/spec.md).

## Интерфейс для других плагинов

Два канала: HTTP на локальном сервере DSH (`/dsh-pet-7340`, без авторизации) и сервис Cordis `petApi7340` на странице (`ctx.get`, без сети).

- [API.md](API.md) — обзор HTTP
- [openapi.yaml](openapi.yaml) — контракт OpenAPI 3.1
- [CORDIS.md](CORDIS.md) — сервис на странице

## Совместимость

Windows, Linux и macOS: overlay в браузере и окно Electron ведут себя одинаково. Прозрачное видео — VP9-alpha webm (Chrome, Edge, Firefox). Safari этот webm не показывает прозрачным; для macOS есть `.mov` в релизе upstream `assets-mov`. Несколько мониторов поддерживаются.
